# Моя Библиотека

## Описание

**Моя Библиотека** — это мобильное приложение-каталог книг, разработанное на Android с использованием Jetpack Compose. Приложение позволяет просматривать список книг с краткой информацией и открывать подробный экран с полным описанием, жанром, годом издания и рейтингом каждой книги.

## Функциональность

- Отображение списка книг (минимум 5 книг) в виде карточек с обложками
- Краткая информация на главном экране: название, автор, жанр, год, рейтинг
- Экран с подробной информацией о выбранной книге
- Полное описание книги
- Навигация между главным экраном и экраном деталей
- Кнопка "Назад" для возврата к списку
- Собственная иконка приложения

## Как запустить

1. **Клонировать или скачать проект**  
   Откройте проект в Android Studio через `File → Open`

2. **Синхронизировать зависимости**  
   Нажмите `Sync Now` после открытия `build.gradle.kts`

3. **Подключить устройство или эмулятор**
    - Выберите эмулятор Android (API 25+)
    - Или подключите физическое устройство через USB

4. **Запустить приложение**  
   Нажмите зелёную кнопку **Run** ▶ или `Shift + F10`

5. **Использование**
    - На главном экране виден список книг
    - Нажмите на любую карточку → откроются детали
    - Нажмите стрелку "Назад" → вернётесь к списку

| Компонент | Где используется |
|-----------|------------------|
| `Scaffold` | Главный экран и экран деталей (каркас с TopAppBar) |
| `LazyColumn` | Список книг на главном экране |
| `Card` | Карточка каждой книги |
| `Row` / `Column` | Верстка внутри карточек и экранов |
| `Image` | Отображение обложек книг |
| `TopAppBar` | Верхняя панель с заголовком и кнопкой назад |
| `Icon` / `IconButton` | Кнопка навигации назад |
| `Text` | Отображение всей текстовой информации |

### 2. Как организована навигация между экранами?

Навигация реализована с использованием библиотеки **Navigation Compose**:

- Создан `sealed class Screen` с маршрутами:
    - `Home` → маршрут "home"
    - `Details` → маршрут "details/{bookId}"

- В `NavGraph.kt` создан `NavHost`, который связывает маршруты с composable-функциями:
    - `home` → `HomeScreen`
    - `details/{bookId}` → `DetailsScreen`

- Переход осуществляется через `navController.navigate()`
- Возврат назад — через `navController.popBackStack()`

### 3. Как передаются данные о книге на экран деталей?

1. При клике на карточку вызывается `onBookClick(book.id)`
2. `HomeScreen` передаёт ID книги в навигацию:  
   `navController.navigate(Screen.Details.createRoute(bookId))`
3. В `NavGraph` параметр `bookId` извлекается из маршрута:  
   `backStackEntry.arguments?.getString("bookId")`
4. По ID находится объект `Book` через `BookRepository.getBookById()`
5. Найденный объект передаётся в `DetailsScreen`

### 4. Где хранятся данные о книгах?

Данные хранятся в `BookRepository.kt` — объекте-синглтоне со списком из 5 книг. Каждая книга содержит:

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | String | Уникальный идентификатор |
| `title` | String | Название книги |
| `author` | String | Автор |
| `year` | Int | Год издания |
| `genre` | String | Жанр |
| `rating` | Float | Рейтинг (0–5) |
| `description` | String | Полное описание |
| `coverResId` | Int | Ресурс изображения обложки |

### 5. Как добавлены изображения обложек?

1. Файлы изображений (JPG) помещены в папку:  
   `app/src/main/res/drawable/`
2. В `BookRepository` каждому объекту присвоен `@DrawableRes id`:  
   `R.drawable.book1`, `R.drawable.book2` и т.д.
3. В UI используется `Image(painterResource(id = book.coverResId), ...)`
